Accessibility review: edition 2.0

Review draft for Gregg and Patricia. Content revision b2bee2e24d0c. Checked October 31, 2026.

Release status: manual assistive-technology review remains open. This package does not yet carry a WCAG 2.2 AA conformance claim. Automated checks, tag inspection and layout checks support review; they do not prove every success criterion.

Three review passes

  1. Source and structure. Checked native checkbox names and descriptions, unique identifiers, internal links, table column and row headers, heading structure, document language, Word heading styles and repeating table headers. The phonetic and Morse letter tables read A to M, then N to Z in HTML. Visual Morse patterns have spoken dit and dah equivalents.
  2. Live browser behavior. Ran axe-core 4.14.0 against WCAG 2 A/AA, 2.1 A/AA and 2.2 AA rule tags. Light and dark modes each reported zero violations, zero incomplete checks, and 28 passing rules. A 320 CSS-pixel iframe with a 305-pixel content viewport, 44-pixel text (twice the default), and WCAG text-spacing overrides reported zero violations, 30 passing rules and 11 contrast nodes requiring manual review. At that setting the page scroll width equaled its 305-pixel content width. Tables retain their own horizontal scrolling where needed.
  3. Export and layout. Checked all 22 PDF/Word section pairs, complete 112-page editions, one-page phonetic alphabet, ten-page Morse section, PDF bookmarks and linked contents. Compared all titles, paragraphs and table cells against the full print PDF and rendered Word/PDF pages. Inspected rendered page contact sheets and critical alphabet/Morse pages. A master-edit probe confirmed that rebuilding changes the section PDF, full PDF and master HTML together.

Browser tasks verified

  • Space toggles a focused native section checkbox and updates the page count.
  • Clearing every section disables the combined PDF and Word download buttons.
  • Reading an unselected section opens it and moves focus without changing the selection.
  • An individual phonetic PDF generates successfully in the browser; focus returns to its download button.
  • Section choices, saved profiles, optional source pages and front-facing section starts passed generator checks.
  • At narrow width and enlarged text, download controls, legends and long headings wrap. These checks found overflow that the initial automated audit did not report; it was repaired.

PDF tags and fonts

The tagged/ folder contains the full book and 22 individual PDF review exports from the current Word files. All 23 have a structure tree, a marked-document flag and en-US language. The full book has 112 heading tags, 32 table tags and 70 table-header tags. All 70 headers have column scope. The tagged full book retains all 112 planned pages and all checked body content.

The root PDF and PDFs in sections/, including custom PDFs created in the browser, are fixed-layout print editions. They have bookmarks but are not tagged. For semantic reading use the master HTML, Word files, or the separately labeled tagged review PDFs. The browser does not convert custom selections to tagged PDFs; download selected Word, then export with tagging in a suitable document application.

Authoring and print faces are Helvetica and Helvetica Bold. Word declares Helvetica. This environment's tagged PDF export embeds Nimbus Sans, a Helvetica-compatible substitute; it does not embed DejaVu. The source CSS uses Helvetica, Arial, then the system sans serif. Main print content is 22 points; headings, notes, references and running information use the sizes documented in READ_ME_FIRST.txt.

Manual checks for the release review

  • Use the group's actual screen readers and document readers: names, checkbox state announcements, focus order, status messages, heading navigation, table navigation, and Morse speech. VoiceOver, NVDA and JAWS were not run here.
  • Check the 11 contrast items marked incomplete in the enlarged/spacing browser audit. The theme uses the same high-contrast foreground/background values as the light-mode audit, but these individual renderings still need human review.
  • Inspect PDF tag order and table navigation in the intended reader, especially the four-column printed alphabet tables. HTML provides two sequential letter tables. No independent PDF/UA validator was run; a tag tree is not PDF/UA certification.
  • Test browser zoom at 400 percent, mobile use, forced colors, and the group's preferred magnifier settings. Narrow viewport testing covered reflow at 320 CSS pixels but did not operate the browser's 400-percent zoom control.
  • Check plain-language comprehension with intended readers. This edition has not been validated as fifth-grade reading material. Define unfamiliar terms and add examples where the reviewers find gaps.
  • Print the one-page test at actual size, double-sided where appropriate, and check glare, punch clearance, lamination and field readability.
